# 指令与工具参考

## 群里怎么用

只有 **@机器人** 之后的内容才会被处理(单聊直接说话即可)。

```
@机器人 /AI 你的问题        → 和 AI 对话
@机器人 你的问题            → 同上(/AI 可以省略)
@机器人 /帮助               → 指令列表
@机器人                     → 只 @ 不说话,也会回指令列表
```

如果 QQ 后台开启了「机器人可查询群内所有消息」(全量接收),机器人能看到群里每一条消息,
但**只有 /AI 开头的消息**才会触发 AI,其余聊天完全静默、不占用模型资源:

```
/AI 你的问题                → 和 AI 对话(不需要 @)
大家中午吃什么              → 不触发,机器人不回应
```

## 指令一览

| 指令 | 别名 | 作用 |
| --- | --- | --- |
| `/AI <内容>` | `/a`、`/问`、`/ask` | 交给 Agent 处理 |
| `/帮助` | `/help`、`/菜单`、`/指令`、`/?` | 显示指令列表 |
| `/查信息` | `/info`、`/whoami`、`/我的信息` | 显示你的 openID 与群聊 openID(拿去面板授权用) |
| `/压缩` | `/compress`、`/总结`、`/compact` | 把聊天记录压成摘要 |
| `/记忆` | `/memory` | 看这个会话记住了哪些事 |
| `/状态` | `/status` | 看当前运行状态 |
| `/清空` | `/delete`、`/clear`、`/reset`、`/重置` | 清空这个会话的上下文与记忆 |

## AI 有哪些工具

| 工具 | 干什么 |
| --- | --- |
| `deploy_site` | 写好的网页直接部署,返回一个 8 位 ID 的链接 |
| `update_site` | 改已部署的项目(可以用 ID,也可以直接用项目名),倒计时重新算 |
| `list_sites` | 列出在线项目(ID、链接、剩余时间、访问次数) |
| `read_site` | 读某个项目的文件内容 |
| `delete_site` | 删掉项目,顺带释放它占的空间 |
| `fs_write` / `fs_read` / `fs_list` / `fs_edit` / `fs_delete` | 沙盒草稿区:先写文件、改好了再部署 |
| `fs_deploy` | 把沙盒里的文件一次性部署出去 |
| `web_search` | 联网搜索(需要先在面板配搜索接口) |
| `fetch_url` | 抓网页正文 |
| `calc` | 精确计算,不心算 |
| `now` | 当前时间(北京时间) |
| `remember` / `recall` / `forget` | 长期记忆 |
| `random` | 掷骰子、抽签、随机数 |
| `encode` | Base64 / URL / 十六进制互转,JSON 格式化 |
| `mcp_*` | 面板里接的 MCP 服务器提供的工具 |

## HTTP 路由

| 路径 | 说明 |
| --- | --- |
| `/administrator` | 管理面板(需要登录) |
| `/administrator/api/*` | 面板接口(需要登录) |
| `/qq/webhook` | 腾讯回调入口,**只在 WebHook 模式下启用**;WebSocket 模式下访问返回 403 |
| `/<8位ID>` | 部署出来的网页 |
| `/<8位ID>/<文件>` | 项目里的其它文件 |
| `/<8位ID>/__data/<键>` | 部署页面存取小数据(GET 读、POST 写) |

> 早期版本的 `/health` 与 `/check` 已删除 —— 它们不需要登录就能看到配置状态,等于免费送情报。
> 现在要看运行状态,登录面板的首页就行。
