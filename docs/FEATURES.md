# 功能总清单(逐项核对)

这份清单按模块列出全部功能,每一项都写了「怎么验证」。
部署完成后可以照着一条条打勾;发现问题时,把编号和现象发给我。

> 面板地址统一是 `https://<你的地址>/administrator`。
> 命令行都在仓库根目录执行。

---

## 一、部署与更新

- [ ] 1.1 连接 GitHub 仓库后,Cloudflare Workers Builds 能自动构建
  - 验证:CF 后台 → Workers & Pages → 你的 Worker → Deployments,能看到构建记录
- [ ] 1.2 往 main 推一次提交会自动重新部署(OTA)
  - 验证:改一行文档并 push,Deployments 出现新记录,线上页面随之更新
- [ ] 1.3 构建时自动清理 README / docs 等描述文件
  - 验证:构建日志出现 `[strip-docs] 已清理 …`
- [ ] 1.4 本地 `wrangler dev` / `wrangler deploy` 不会删你的文档
  - 验证:本地执行后只打印 `[strip-docs] 本地环境,跳过`
- [ ] 1.5 构建失败可以回滚
  - 验证:Deployments → 选上一个成功版本 → 回滚
- [ ] 1.6 更新不会丢 D1 / KV / R2 里的数据
  - 验证:更新前后,面板里的配置、项目、日志都在

## 附:一条命令验证全部

```bash
npm run test:all
```

全绿就说明代码层面没有已知问题。
